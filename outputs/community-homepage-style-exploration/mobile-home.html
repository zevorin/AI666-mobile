移动首页走查规则

页面目的

移动首页复用 Web 首页的 Banner、模块标题、分类名称和内容对象，并提供活动、创作、积分与新手任务四个高频入口。

页面骨架

首页不设置顶部应用栏；底部五项是唯一一级导航，五项文字保持同一水平基线，创作加号单独上浮，首屏从 Banner 直接开始。

内容一致

Banner 固定展示 3 个当前对象；点击后分别进入移动视频创作、移动生图挑战详情和移动视频创作，不回落桌面页面。爆款作品沿用 Web 端全部、短剧漫剧、文本内容、图片生成、视频生成和 Prompt 6 个分类。

快捷入口

Banner 下方固定展示活动中心、AIGC 生成、积分中心和新手任务；入口使用正式模块名并进入对应移动页面，不承载说明文案或移动端独立业务对象。

筛选与列表

分类在当前页完成筛选，不跳转桌面页面；作品使用双列瀑布流，首行优先放满两个可见作品，再按两列剩余高度补位。

验收

360/390/430 无页面级横向溢出；底部五项文字水平对齐且创作加号突出于底栏；4 个快捷入口均进入移动页面；3 个 Banner 均不得跳转桌面页面；6 个分类切换时 URL 不变且滑动指示器跟随；存在两个以上作品时首行必须占满两列，卡片继续按媒体原始比例自适应高度。
