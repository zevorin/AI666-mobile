创作工作台走查规则

页面目的

用同一对话式工作台承接图片生成、剧本创作与视频生成；灵感输入是主入口，模式、参考素材、模型和参数作为就近设置。

同款上下文

从图片或视频详情进入时展示来源作品，带入媒体类型、提示词、模型与允许复用的参数；剧本创作从故事设定开始，用户确认后才发起创作。

输入层级

页面作为独立全屏工作台，不显示一级 TabBar；顶部提供返回、记录筛选和生成记录。图片与视频在同一输入面板内展示参考素材，剧本模式隐藏附件入口。

图片参数

图片生成展示当前可用模型、1K / 2K / 4K 分辨率与画面比例；视频模式展示 470p / 720p / 1080p 分辨率、比例与 4–20 秒时长。

模型与积分

模型、分辨率、比例与时长统一使用 Web 端描边胶囊和向上展开菜单；模型保持单选并同步更新预计积分，比例项使用横、竖、方形图标辅助识别。

全局创作入口

底部创作入口是全局发布动作，点击后先选择 AIGC 生成或发布闪念；当前页承接 AIGC 生成，发布闪念进入独立全屏编辑页。

记录承接

生成记录从标题右侧入口打开底部层；进行中记录恢复原任务，成功记录进入对应结果或作品详情。

状态承接

发起创作后按日期展示本次参数、提示词与任务卡；进度在 3 秒内从 0% 自动推进至 100% 并展示结果，图片、视频与剧本完成后统一进入同页沉浸结果详情。

验收

360/390/430 宽度下输入区不被安全区或键盘遮挡；顶部筛选、三模式切换、模型弹窗、参数、重新生成和三种结果详情均可操作；不自动扣减积分。
