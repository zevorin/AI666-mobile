让每个页面
说同一种语言。

01 / Principles

先统一语义，
再统一像素。

字号相同不代表作用相同。每段文字先确定任务：导航、阅读、操作、标题或数据展示，再选择对应 role。禁止为了“塞下”内容临时新增 10px、13.5px、15.5px 等散值。

11px 是底线，不是正文

TabBar 与非阅读型微标签可使用 11px。首页爆款筛选使用 13px；普通说明从 12px 起，正文统一 14px。

一个角色，一个 token

页面标题、区块标题、卡片标题和正文分别使用固定变量；旧组件通过兼容层映射，不在页面内重写字号。

层级靠组合，不只靠大小

字号、字重、行高、颜色和间距共同表达层级。辅助信息使用次级颜色，不用无限缩小字号。

中文优先可读

正文保持 1.57 倍行高，标题使用轻度负字距。长中文不使用全大写式宽字距，数字用等宽特性。

控件保持可触达

常规按钮文字 14px、高度 44px；紧凑按钮 36px。首页爆款筛选项视觉高度 32px，外层轨道最小高度 40px。

视觉大字允许例外

首页 Banner 与社区重点内容可使用表达性大字；仍必须遵循展示字体、对比度和移动端安全宽度。

!事实：底部 TabBar 使用 11px；业务 Tab 统一使用 13px 或 18px。规范决策：内容、模式和状态筛选使用风格 A 的胶囊轨道与暖金滑块；页面一级频道使用风格 B 的大号文字与短暖金下划线，不再创建第三套 Tab。

08 / Handoff

设计与开发
落地规则。

这些规则用于新增页面、改版和验收。若业务确实需要新层级，应先更新 token 与本规范，再进入页面实现。

  1. 先选语义 role，再写组件。不要根据单张设计图目测一个新字号。
  2. 11px 只给 TabBar 与微标签。首页爆款作品筛选固定 13px；时间、帮助、卡片副标题至少 12px，正文 14px。
  3. 首页筛选不与其他 Tab 混用。只复用 `.mobile-home-filter-tab` 及其指示器、键盘行为和动效参数。
  4. 按钮和输入标签统一 14/20 Semibold。常规触控区至少 44px，紧凑操作至少 36px。
  5. 长文本必须用正文行高。详情、评论、规则和说明使用 14/22，不压缩成 Caption。
  6. 弱层级优先调整颜色。Primary、Secondary、Tertiary 三层足够，不用透明度叠加到不可读。
  7. 数字启用 tabular-nums。浏览、喜欢与内容统计保持对齐；表达性大字可超出 36px。
  8. 验收 360 / 390 / 430 三档。检查无横向滚动、标题不碰撞、正文不截断、tabbar 不变形。
