01 / Principles

先定语义，再定样式

页面可以有不同内容密度，但相同语义必须共享同一 token。活动主题只改变活动表达，不扩散到商城、创作、详情、个人资料等普通产品页面。

01

主色只有一个

非活动页面的主操作、选中态、重点数字和 Focus ring 统一使用暖金。

02

标题按角色分级

17px 是 App Bar，20px 是区块标题，24px 是内容主标题，30px 仅留给少数 Hero。

03

例外必须有名字

活动主题色、状态色、品牌字体都要有明确作用域，不允许用页面覆盖悄悄改写通用组件。

02 / Color

近黑空间，暖金动作

暖金承担产品动作与选择，暖白建立阅读层级。蓝、紫、薄荷和酸橙用于内容标签、状态或活动，不作为普通页面主操作色。

03 / Typography

十个字号，五档字重

正文使用系统中文字体栈，展示数字与少量英文标签使用 Montserrat Mobile。禁止写入 620、650、680、720、850 等中间字重。

05 / Shape

4px 网格，12px 工作圆角

当前系统不再使用旧交接的 16px 卡片与 24px 弹层分级。控件、卡片、作品和弹层统一在 12px 工作圆角上，胶囊控件使用 999px。

06 / Buttons

三档动作按钮

按钮尺寸只由使用场景决定，颜色只表达语义。非活动主按钮统一暖金，活动页可以使用明确的 campaign action 变量。

07 / Tabs

两种 Tab，不再新增

Style A 用于筛选和状态；Style B 只用于社区频道级导航。普通页面选中态统一暖金，未选文字不得低于可读对比度。

Style A · Segmented

36px Tab，44px 轨道，13px 文字，暖金滑块。

Style B · Channel

仅社区使用；44px 触控高度，18/19px 展示文字。

08 / Surfaces

层级来自明度，不来自乱加圆角

普通卡片用轻描边和内高光，重要卡片增加阴影或背景图。输入控件保持深色玻璃底、12px 圆角和暖金 Focus ring。

普通卡片

12px 圆角、1px 暖白描边、轻微内高光。用于记录、消息和资料行。

内容卡片

媒体与文案属于同一裁切容器；标题 16px，辅助信息 12px。

表单控件

44px 以上高度，14–16px 输入文字，Focus 使用 `--ds-focus-ring`。

09 / Navigation

导航稳定，状态克制

一级页使用五项 TabBar；二级页使用 44px 返回按钮和 17px 居中标题。成功、危险和处理中状态不得借用主色。

一级导航

  • 首页、社区、AI创作、活动、我的固定五项
  • 当前项使用暖金图标、文字和短下划线
  • 中央创作入口可突出，但不改变标签名称

二级导航

  • App Bar 标题固定 17px / 600 / 24px
  • 返回和关闭保留 44×44px 触控区
  • 状态绿、危险红、信息蓝只表达结果
10 / Activity exception

活动可以有主题色，但不能污染全局

活动中心、活动详情、生图挑战和新手任务可以根据活动主视觉使用独立 action 色。退出活动作用域后立即回到暖金。

Prompt 共创香槟活动色
生图挑战珊瑚活动色
新手任务酸橙活动色
活动作用域：activity / activity-detail / campaign-detail / tasks
普通作用域：首页、社区、创作、详情、积分、商城、邀请、消息、个人资料

12 / Acceptance

发布前检查

视觉规范不能代替真机与辅助技术测试。以下是每次改动的最低验收线。

视觉与响应式

  • 360 / 390 / 430px 无页面级横向滚动
  • 可见文字不低于 11px
  • 普通文字对比度目标至少 4.5:1
  • 活动主题不扩散到普通页面

交互与语义

  • 图标按钮至少 44×44px
  • Tab 同步 aria-selected 与视觉状态
  • Focus ring 清楚且不被裁切
  • 减少动态模式下不隐藏关键信息
