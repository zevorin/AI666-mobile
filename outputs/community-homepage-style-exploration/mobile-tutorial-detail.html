第十五期：OMate API 配置教程

快速完成模型 API 接入与常用参数配置，并通过首次对话确认连接状态。

本节你将完成

  1. 确认模型服务地址和可用模型。
  2. 在目标工具中填写 API 地址与访问凭证。
  3. 发起测试对话并处理常见连接错误。

开始前准备

准备好可用的模型服务地址、访问凭证与目标工具。请妥善保管访问凭证，不要在截图、评论或公开内容中展示完整密钥。

操作提示

完成配置后先发送一条简短测试消息。若连接失败，请依次检查服务地址、模型名称和访问凭证是否准确。
