# AI666 Mobile × Web 视觉统一设计说明

日期：2026-08-21  
范围：`outputs/community-homepage-style-exploration/` 下 24 个移动端 H5 页面

## 目标与边界

- 保留移动端现有信息架构、五项底部导航、详情页返回关系、页面内容顺序和交互逻辑。
- 视觉语言对齐 `AI666-web` 当前“沉浸式暗场创作空间”：近黑背景、暖金主动作、酸橙增长强调、玻璃表面、胶囊控件和线型图标。
- 素材只复用 Web 项目现有品牌、作品、活动、商城、消息、教程和首页首帧；不生成新的视觉素材。
- 当前迭代不制作动画。共享样式显式关闭 transition、animation 和 smooth scrolling；加载状态仍保留文字和静态图标反馈。
- 已确认的移动邀请函版式保留，不用桌面邀请页覆盖它。

## 实现策略

采用“共享令牌 + 共享组件覆盖 + 关键页面素材映射”，而不是逐页重写。所有页面继续加载 `mobile-h5.css`；该文件导入 `mobile-design-tokens.css`，作为颜色、圆角、字体、间距、阴影的单一来源。已有 HTML 类名继续作为组件 API，避免破坏现有脚本和验证规则。

Web 素材复制至 `assets/web/`，保证移动交付包独立运行，不依赖相邻的 `AI666-web` 目录。首页、社区、活动、创作、积分、商城和个人中心使用不同的 Web 头图，但组件表面和控件状态不分叉。

## 统一组件

- 按钮：`primary / secondary / compact` 三种规格，统一胶囊圆角和 40px 以上触控高度。
- Tab/筛选：所有选中态统一为暖金浅底、金色文字、金色轻描边。
- 卡片：普通卡片 16px，Hero/弹层 24px；只用背景层级、轻描边和内高光区分层级。
- 表单：输入、选择器、创作输入框统一 12px 圆角、深色玻璃底、暖金 Focus ring。
- 导航：底部五项复用同一选中胶囊语言，中央创作按钮保留原有突出层级。
- 状态：积分与主动作使用暖金，邀请增长使用酸橙，成功与危险分别使用绿/红语义色。

## 验收

- 360、390、430 宽度不得出现页面级横向滚动。
- 24 个页面的本地 CSS、JS、图片、视频和图标引用必须可访问。
- 首页筛选、社区频道、创作模式与设置、底部弹层、详情动作和底部导航继续可操作。
- 页面不触发 CSS transition 或 animation；视觉变化只通过静态状态切换完成。

## 首页 V3 质感调整

首页在不改变暖金主题和核心入口的前提下，采用更具触感的深色悬浮层级：Banner 文案使用大字号展示，四个快捷入口收敛为悬浮胶囊 Dock；首页不增加账户头像或顶部操作按钮，爆款作品沿用双列瀑布流向下浏览，底部导航沿用全项目共享 Tabbar。参考图只用于提取暗场环境光、大圆角、胶囊控件和卡片层级，不复用其荧光绿色彩、加密货币文案或业务结构。
