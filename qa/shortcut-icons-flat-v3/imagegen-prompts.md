# Semi-flat shortcut icon ImageGen prompts

Mode: built-in ImageGen edit mode. Each existing 3D icon was used as an edit target. The generator returned RGB images with a rendered checkerboard; the checkerboard was removed locally and clean RGBA assets were saved as versioned project files.

Shared prompt:

> Use case: style-transfer. Asset type: mobile homepage shortcut icon, displayed around 64 px. Make this existing icon only moderately flatter and less AI-rendered while preserving its subject. Use a polished semi-flat app illustration style, about 70% flat and 30% dimensional, with clean simplified color planes, restrained shallow bevels, subtle soft shadow, and limited small highlights. Preserve the current recognizable colors, centered composition, silhouette, object arrangement, viewing direction, proportions, padding, and square canvas. Reduce extrusion depth, plastic volume, glossy reflections, neon bloom, rim glow, and spark effects by roughly half. Keep strong readability at 64 px. No photorealism, thick 3D toy plastic, glassy materials, excessive glow, blown highlights, fuzzy halo, background, card surface, frame, text, letters, numbers, watermark, or new elements.

Subject variants:

- Activity center: coral-orange star, purple event ticket, small cyan sparkle.
- AIGC creation: purple movie clapperboard, play triangle, small sparkle.
- Points center: stacked golden coins, star emblem, small cyan sparkle.
- Beginner tasks: violet checklist, yellow checks, orange-blue rocket.
