# 移动端按钮规范

更新日期：2026-08-31

## 结论

审计 24 个移动端页面、110 个首屏可见按钮或按钮型控件后，原样式按浏览器最终计算值共有 34 组尺寸组合；统一后降为 23 组。这个原始数字仍混合了动作按钮、图标按钮、筛选 Tab、文字操作、不同内边距和上传区域，不能直接当成产品按钮种类。

统一后，产品动作按钮只保留 3 档；连同 Tab、图标和特殊内容控件，按钮型控件归为 7 类。

| 类型 | 高度 | 文字 | 水平内边距 | 典型用途 |
| --- | ---: | ---: | ---: | --- |
| 紧凑动作 | 36px | 12px / 20px | 14px | 卡片内“去浏览”、复制邀请码、小型辅助操作 |
| 默认动作 | 44px | 14px / 20px | 16px | 商城兑换、分享、普通主次按钮 |
| 强动作 | 50px | 14px / 20px | 20px | 底部固定主按钮、发布、保存、提交 |
| 工具栏动作 | 44px | 12px / 20px | 随布局 | 点赞、评论、收藏、分享 |
| 分段筛选（Style A） | 36px | 13px / 20px | 16px | 首页筛选、生成类型、记录状态 |
| 图标按钮 | 44px 触控区 | 无可见文字 | 0 | 返回、关闭、头像入口 |
| 文字操作 | 36px 或 44px | 12px 或 13px / 20px | 随上下文 | 关注、回复、查看全部、写评论 |

## 合并规则

- `compact` 类名必须稳定解析为 36px 高、12px 字，页面样式不得再把它覆盖成 38px 或 44px。
- 普通按钮统一为 44px 高、14px 字；主次、危险等语义只改变颜色，不改变尺寸骨架。
- 固定底栏和全宽提交按钮统一为 50px 高、14px 字。
- Style A 分段筛选统一为 36px 高、13px 字；社区频道的 Style B 属于页面级展示导航，保留 44px 触控区和 18/19px 字号。
- 返回、关闭等图标按钮保留至少 44px 触控区；个人 ID 复制是密集行内例外，使用 36px 触控区。
- “添加图片或视频”“添加参考图”是 64px 高的内容上传区域，不并入普通动作按钮。
- 颜色、描边、填充和光效继续表达主按钮、次按钮、选中态和危险态，不作为新的尺寸类型。

## 单一来源

- 尺寸和文字 token：`mobile-design-tokens.css`
- 最终按钮契约：`mobile-h5-controls.css`
- 加载顺序：`mobile-h5-controls.css` 必须位于所有页面模块之后；带独立主题样式的邀请页和个人页需再次最后加载该契约。

新增按钮时优先复用 `.mobile-button`、`.mobile-button.compact` 或 `.mobile-action-primary`。只有交互结构明显不同（图标、Tab、工具栏或上传区域）时才新增控件类型。
