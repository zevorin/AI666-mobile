# 移动端个人中心布局优化设计

日期：2026-08-25

## 设计结论

本次属于保留式重设计。保留个人中心现有信息架构、近黑背景、暖金交互色、3D 品牌素材、链接关系、复制 ID、消息角标和底部 TabBar，仅优化正文布局与视觉层级。

Design Read：面向 AI 创作者的移动端个人资产中心，采用克制的黑金消费级语言，突出身份、资产和高频创作入口。

- `DESIGN_VARIANCE: 6`：使用一张横向主卡与两张并列次卡形成明确主次。
- `MOTION_INTENSITY: 3`：不增加自动动画，只保留按压和键盘焦点反馈。
- `VISUAL_DENSITY: 5`：首屏信息完整，但避免统计区和入口区全部套用重卡片。

## 页面结构

1. 身份区保留头像、昵称、用户 ID、消息和设置入口，压缩操作按钮占位，改善 360px 宽度下的姓名展示空间。
2. 三项数据改为无背景统计带，通过上下边线和内部细分隔组织，不再作为独立重卡片。
3. 内容区使用“主作品 + 双快捷入口”：我的作品为横向通栏主卡；我的闪念与我的收藏并排，保持相同结构。
4. 成长与权益使用双列卡片，缩短页面高度；AI 商城与邀请有礼保持同等权重。
5. TabBar 的 HTML、CSS、脚本和交互保持不变。

## 视觉与交互规则

- 页面背景沿用近黑色，唯一 UI 强调色为暖金；素材自身色彩不作为界面状态色。
- 卡片统一 14px 圆角；圆形只用于消息、设置和箭头等图标按钮。
- 正文辅助文字不低于 12px，TabBar 继续沿用现有 11px 基准。
- 点击反馈使用轻微亮度变化和 `scale(0.985)`，不增加入场、循环或滚动动画。
- `prefers-reduced-motion` 下移除过渡与变形。

## 响应式与验收

- 360、390、430 三档均保持两列快捷入口，不出现横向溢出。
- 昵称和 ID 可截断，操作按钮不能挤出视口。
- 所有原有链接、可访问名称、复制 ID 与消息角标继续工作。
- TabBar 的位置、尺寸、选中态、中央创作入口和交互保持原样。
