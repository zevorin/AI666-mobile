# 移动端双风格 Tab 统一设计

## 目标

将移动端所有承担互斥切换或筛选的 Tab 收敛到两种既有视觉语言，消除生成记录、我的内容、消息、投稿和积分记录各自维护样式的情况。

## 已确认规则

- 风格 A：用于内容类型、生成模式和状态筛选。基准是首页“爆款作品”和 AIGC 生成页，表现为深色胶囊轨道、暖金滑动选中层、13px 文案和横向溢出滚动。
- 风格 B：用于页面一级频道。基准是社区顶部频道，表现为透明背景、大号频道文字和短暖金下划线。

风格 A 应用于首页爆款、AIGC 生成、社区内 AIGC、生成记录、我的内容、消息类型、投稿状态和积分记录。风格 B 应用于社区顶部“社区推荐 / AIGC / 闪念 / 教程”。

## 组件与交互

共享类 `.mobile-tabs-style-a` 和 `.mobile-tabs-style-b` 只负责视觉语义，保留各页面已有业务类和数据属性。风格 A 使用同一个 `.mobile-home-filter-indicator` 滑块实现，脚本负责初始化、尺寸变化、选中态变化和方向键导航；已有筛选、内容面板和 URL 状态逻辑继续负责业务结果。风格 B 沿用社区频道现有的固定下划线交互。

所有 Tab 容器使用 `role="tablist"`，按钮使用 `role="tab"` 和 `aria-selected`。已有代码依赖 `aria-pressed` 的页面暂时同时保留该属性，避免改变现有行为。窄屏下风格 A 可横向滚动，风格 B 保持频道文字可扫描；减少动态偏好下降低滑块动画。

## 验收

- 全部 Tab 容器都明确使用风格 A 或 B，不保留第三套可见样式。
- 360px、390px、430px 下无页面级横向溢出。
- 点击、方向键和程序化选中后，文字与滑块状态一致。
- 首页、社区、AIGC 生成、生成记录、我的内容、消息、投稿和积分记录的现有内容逻辑不回归。
