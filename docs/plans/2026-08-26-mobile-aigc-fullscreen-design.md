# 移动端 AIGC 全屏创作页设计

## 目标与依据

把现有 `mobile-create.html` 从一级导航页改为独立全屏创作页。页面不显示底部 TabBar，顶部提供返回与生成记录入口；输入区固定在安全区上方；点击当前模型时打开轻量模型弹窗。视觉参考用户提供的 Flova 移动端截图，但沿用多元拾光的深色、暖金、14px 圆角和现有 Remix Icon 资产。

已确认：现有页面包含图片、剧本、视频三种模式、来源复用、生成记录、任务恢复及结果回流。合理推测：用户希望参考 Flova 的信息层级和交互密度，而不是复制其品牌、模型或背景。公开页面无法完整验证参考站内部生成流程，因此不引入截图之外的交互假设。

## 方案取舍

1. 仅隐藏 TabBar：风险最小，但模型仍由大设置抽屉承载，不能满足“小弹窗”。
2. 完整复制 Flova：视觉相似度高，但会替换现有设计系统并损害已有参数、任务和来源链路。
3. 保留业务状态并重构页面外壳：移除 TabBar，加入标准返回栏，把模型选择拆成紧凑弹窗，其余模式与生成状态继续复用。采用此方案。

## 页面结构

- 顶部栏：左侧 44px 返回按钮；中间标题“AIGC 生成”；右侧 44px 生成记录按钮。返回优先使用浏览历史，无历史时进入移动首页。
- 内容区：保留来源卡、空状态说明和三条创作灵感。生成后的用户输入与任务卡继续插入同一线程。
- 固定输入区：模式选择、提示词文本域、附件、模型、参数和生成动作在同一卡片内。输入区与底部安全区保持 12px 间距，不再为 TabBar 预留高度。
- 模型弹窗：遮罩上方显示宽度受限的悬浮面板，只展示当前创作模式的模型列表；选择后立即更新摘要并关闭。弹窗可通过遮罩、关闭按钮和 Escape 关闭。
- 参数：图片显示比例；视频显示比例和时长；剧本不显示可变参数。紧凑参数按钮按既有选项循环切换，避免重新引入大型设置抽屉。
- 生成记录：继续使用现有底部抽屉，避免改动记录与任务恢复链路。

## 状态、异常与可访问性

- 模式切换会同步提示词标签、字数上限、附件入口、模型列表和参数按钮。
- 空提示词仍原位报错并聚焦文本域；附件保持模拟选择反馈；生成任务逻辑不变。
- 模型按钮使用 `aria-expanded` 和 `aria-controls`；弹窗使用 `role="dialog"`、`aria-modal`；模型项维持单选状态。
- 主要触控目标不小于 44px；360/390/430px 无横向溢出；尊重减弱动效与减弱透明度偏好。

## 验收

- 页面无 `.mobile-bottom-nav`，也不再使用 `.has-bottom-nav`。
- 顶部返回按钮可用，生成记录入口可用。
- 三种模式均可打开对应模型小弹窗、选择模型并更新输入区摘要。
- 图片比例、视频比例和时长可切换；剧本隐藏附件和参数。
- 提示词提交、任务状态推进、结果预览、来源复用和 URL 状态恢复保持可用。
- 浏览器控制台无错误，360/390/430px 的默认态和模型弹窗态通过视觉检查。
