# 移动端 AIGC 创作页改造方案

## 设计判断

这是一次保留式改造，不改变现有生成任务、结果页、生成记录和底部导航链路。目标用户是需要在手机上快速组织创作灵感的社区创作者。视觉语言延续多元拾光现有的深色底、暖金强调色和 14px 圆角系统，避免常见的紫蓝 AI 渐变与无功能装饰。

设计参数：`DESIGN_VARIANCE 6`、`MOTION_INTENSITY 4`、`VISUAL_DENSITY 6`。

## 现状问题

- 首屏中心区域大面积留空，但没有提供可操作的灵感辅助。
- 提示词输入是页面核心任务，却被压缩成单行；模型和积分设置的视觉权重更高。
- 模式、模型、积分、附件和提交动作被分散在多个相近容器内，层级不清晰。
- 提示词依赖占位符表达用途，缺少持续可见的字段标签。

## 方案

1. 保留标题、生成记录、三种创作模式、设置抽屉和固定底部输入区。
2. 将空状态改为创作引导区，提供图片、剧本、视频三个真实示例。点击示例会切换到对应模式并填入提示词，但不会自动提交或扣减积分。
3. 将输入区重排为三层：创作类型、带可见标签的大文本输入、附件/模型/积分/生成动作。
4. 保持单一暖金强调色。卡片和输入使用 14px 圆角，分段选择器使用胶囊形，建立清晰的形状规则。
5. 只加入用于层级建立和点击反馈的轻动效，并在 `prefers-reduced-motion` 下关闭进入动画。

## 状态与异常

- 空状态：展示创作说明和三个示例提示词。
- 输入错误：在输入框下方原位显示错误并聚焦文本区。
- 生成中、成功、失败和状态待确认：继续使用现有任务卡逻辑。
- 剧本模式：隐藏附件入口，输入上限调整为 5000 字。
- 来源复用：继续展示现有来源卡，并保持带入提示词逻辑。

## 验收

- 360px、390px、430px 宽度无横向溢出。
- 三个示例均能正确切换模式、填入文本并更新模型摘要。
- 模式切换、设置抽屉、附件、提交、生成记录与结果回流保持可用。
- 所有主要触控目标不小于 44px，键盘焦点可见，减弱动效偏好生效。
