# 移动端编辑资料与 AI 商城 Taste 优化

日期：2026-08-30

## 设计边界

- 模式：Redesign - Preserve，保留现有品牌、信息架构与业务路径。
- 页面：`mobile-profile-edit.html`、`mobile-exchange.html`。
- 内容约束：不新增或删减可见文字、字段、账号绑定项、商品、按钮、弹层与跳转。
- 交互约束：保留现有 JavaScript 选择器、资料保存跳转、兑换确认、处理中、成功、余额刷新和记录入口。

## Design Read

这是面向社区用户的移动端产品界面，使用克制、内容优先的暗色品牌语言，沿用项目现有原生 CSS 设计系统。

- `DESIGN_VARIANCE: 5`
- `MOTION_INTENSITY: 3`
- `VISUAL_DENSITY: 5`

## 现状审计

编辑资料页的头像、字段、保存与账号状态使用相近的玻璃卡权重，操作层级不够清晰。AI 商城保留了完整商品与兑换流程，但商品卡按钮过小，原有宇航员主视觉不够突出，目录扫描效率偏低。

## 落地方案

编辑资料页在用户补充的参考图基础上采用主流产品的个人信息排版：头像独立居中，编辑入口叠放在头像右下；昵称和个人简介按单行信息项组织，左侧为字段名、右侧为当前值，并保留原表单的直接编辑能力。账号绑定作为第二个分组列表呈现手机号、微信号与绑定状态，保存按钮固定在底部操作栏中。

AI 商城强化现有宇航员素材和积分余额，不引入新素材。商品仍为原有两列八项目录，统一提高标题、价格和按钮的可读性，按钮扩展为完整卡片宽度。确认与成功弹层沿用原内容和流程，只校准表面、间距与底部操作区。

## 验收结果

- 320、390、430 宽度均无横向溢出。
- 编辑页保持 2 个字段、2 个账号绑定项和 1 个保存动作。
- 商城保持 8 件商品，所有商品按钮高度为 44px。
- 商城记录入口高度为 42px，符合项目 40px 以上触控基线。
- 资料保存可返回个人中心。
- 头像为独立居中的资料头部；昵称和个人简介为两条设置行，且仍使用原表单字段。
- 保存按钮固定在底部操作栏中，头像编辑入口具备 44 × 44px 触控区。
- 兑换确认、兑换成功、余额刷新与记录入口可连续工作。
- 图片资源全部成功加载，两页控制台无错误。
- 主按钮文字在金色背景上的最低对比度为 11.87:1。
