# 移动端生成记录全屏页设计

## 目标

将 AIGC 生成页中的生成记录底部弹层改为独立全屏页面。顶部导航复用 AIGC 生成页的返回按钮、居中标题和深色背景，记录内容在 360px、390px、430px 宽度下保持可扫描、可点击且不横向溢出。

## 信息结构

- 顶部导航：返回、生成记录标题、等宽占位。
- 类型筛选：全部、图片、视频、剧本。
- 记录摘要：显示当前筛选结果数量。
- 日期分组：今天、昨天。
- 记录行：真实预览图、标题、生成类型与花费积分、模型、状态和进入箭头；模型位于第三行，状态固定在箭头左侧。
- 空状态：筛选无结果时提供返回全部记录的动作。

## 视觉方向

保留现有深色暖金 AIGC 视觉。每个日期只使用一个内容面板，记录行使用稀疏分隔，不为每条记录重复创建独立玻璃卡片。筛选控件为紧凑胶囊，状态文字只在生成中使用暖金强调，已完成状态保持低干扰。

设计参数：`DESIGN_VARIANCE 5 / MOTION_INTENSITY 3 / VISUAL_DENSITY 6`。页面以扫描效率为主，只保留点击和聚焦反馈，不增加自动循环动效。

## 交互与验收

- AIGC 页右上角记录图标直接进入全屏页。
- 筛选按钮支持点击和左右方向键切换。
- 无匹配记录时隐藏日期分组并显示空状态。
- 已有四条记录保持原目标链接，生成中任务继续返回对应创作任务。
- 生成结果页直接访问时，返回 fallback 指向生成记录页。
- 页面无底部一级导航，使用 `100dvh` 保持移动端视口稳定。
